Hey! We now have a LIVE CAMERA version of our project 🎥✊✋✌️

What it is
- live_app.py runs our notebook's exact vision + strategy code on a live webcam.
- The video shows every hand outlined and labelled (ours teal, theirs orange).
- A side panel walks our player through the round:
    1) SHOW: which two hands to show (e.g. "Rock + Paper")
    2) DECIDE: "KEEP YOUR LEFT HAND" in big letters, with a green box around the hand to keep and a red box around the one to pull away
    3) RESULT: the camera reads the two hands left and says WIN / TIE / LOSE, and keeps score
- Private mode (press P) hides the decision until our player presses SPACE, so the opponent can't see it.
- Full guide with pictures: LIVE_DEMO.md in our GitHub repo.

IMPORTANT: it has to run on your laptop, not in Colab (Colab can't see your webcam).

--------------------------------------------------
STEP 1 - Download (once)
--------------------------------------------------
- Python 3.12 (64-bit) from python.org
  -> On Windows, TICK "Add python.exe to PATH" on the first install screen!
- Git from git-scm.com (default options are fine)
- A webcam that can point DOWN at the table (USB webcam on a lamp arm / clamp / small tripod,
  or a phone used as a webcam). A laptop's built-in camera faces you, so it doesn't work well.

--------------------------------------------------
STEP 2 - Install (Windows: open "Command Prompt")
--------------------------------------------------
First time:
  cd %USERPROFILE%
  git clone https://github.com/Kristina-Kojic/3350-AISE.git
  cd 3350-AISE
  py -3.12 -m venv .venv
  .venv\Scripts\activate
  pip install -r requirements.txt

Every time after that (gets everyone's latest changes):
  cd %USERPROFILE%\3350-AISE
  git pull
  .venv\Scripts\activate
  pip install -r requirements.txt

Mac (Terminal) instead:
  cd ~
  git clone https://github.com/Kristina-Kojic/3350-AISE.git
  cd 3350-AISE
  python3.12 -m venv .venv
  source .venv/bin/activate
  pip install -r requirements.txt

--------------------------------------------------
STEP 3 - Test it WITHOUT a camera first
--------------------------------------------------
  python live_app.py --source images\demo
(On Mac: images/demo)
Wait 10-20 seconds (it trains on our photos). A window opens and plays our demo photos with
the hands and decisions drawn. Press Q to quit.
If this works, your setup is good. If not, screenshot the error and send it here!

--------------------------------------------------
STEP 4 - Set up the camera
--------------------------------------------------
- Camera above the MIDDLE of the table, pointing straight down, about 60-90 cm up.
- OUR player at the BOTTOM of the picture, the opponent at the TOP.
  (If it comes out upside down, start with:  python live_app.py --rotate )
- Bright light from above. Dim light is our biggest weakness.
- A plain table (a sheet of paper or card under the hands helps).
- All 4 hands fully in view, not touching, sleeves pulled back.

--------------------------------------------------
STEP 5 - Run it live
--------------------------------------------------
  python live_app.py
Options:
  --camera 1    if the wrong camera opens (try 2, 3...)
  --rotate      if our player shows up at the top
  --private     start with the decision hidden (use this in the competition)
  --adaptive    start with our adaptive strategy

How a round goes:
1. Screen says which two to show. Both players show two hands and hold still about 1 second.
2. Screen says KEEP LEFT or KEEP RIGHT. Keep that hand and pull the other away.
3. Screen shows WIN / TIE / LOSE. Take all hands off the table and the next round starts.

Keys:
  N = next round       SPACE = reveal decision (private mode)
  P = private on/off   A = adaptive on/off
  S = save screenshot (saved in captures/, useful for the report!)
  R = reset score      Q or Esc = quit

--------------------------------------------------
If something goes wrong
--------------------------------------------------
- "python is not recognized" -> reinstall Python with "Add to PATH" ticked, or use py instead of python
- "No module named cv2/mediapipe" -> run .venv\Scripts\activate, then pip install -r requirements.txt
- "Could not open camera" -> close Zoom/Teams/Discord/Camera app, or try --camera 1
- Our hands labelled OPP -> restart with --rotate
- Hand not found / bar never fills -> more light, plain background, spread hands apart
